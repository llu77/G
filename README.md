# LMM Finance - نظام مالي متقدم

نظام إدارة مالية متقدم مع واجهة زجاجية حديثة (Glass Morphism) مبني بأحدث تقنيات 2025.

## ✨ المميزات

### 🎨 التصميم
- **Glass Morphism UI**: واجهة مستخدم حديثة بتأثير الزجاج الم frosted
- **تصميم متجاوب**: يعمل على جميع الأجهزة والشاشات
- **دعم اللغة العربية**: واجهة كاملة باللغة العربية مع دعم RTL
- **رسوم متحركة متقدمة**: باستخدام Framer Motion و CSS الحديث

### 🔧 التقنيات المستخدمة
- **React 19**: أحدث إصدار مع React Compiler و features الجديدة
- **Vite 6**: أداة بناء سريعة وحديثة
- **Tailwind CSS v4**: مع دعم Container Queries و utilities حديثة
- **React Router v7**: مع Data Router و Loaders
- **Recharts v3**: لعرض البيانات والرسوم البيانية
- **Framer Motion**: لإنشاء الرسوم المتحركة السلسة

### 🔐 الأمان والمصادقة
- **مصادقة متقدمة**: دعم بريد إلكتروني، هاتف، وبصمة
- **React 19 Actions**: معالجة النماذج بشكل حديث
- **Optimistic UI**: تحديثات فورية للواجهة
- **تشفير آمن**: حماية البيانات الحساسة

### 📊 لوحة التحكم
- **إحصائيات مباشرة**: عرض الأرباح والمصروفات والموظفين
- **رسوم بيانية تفاعلية**: باستخدام Recharts مع تأثيرات Glass Morphism
- **نشاطات حديثة**: متابعة آخر التحديثات والأنشطة
- **إجراءات سريعة**: وصول سريع للوظائف المهمة

## 🚀 البدء

### المتطلبات
- Node.js 18+ أو أحدث
- npm أو yarn
- Cloudflare API Token (للنشر)

### التثبيت

1. **نسخ المشروع**:
```bash
git clone [repository-url]
cd lmm-finance-advanced-system
```

2. **تثبيت الاعتمادات**:
```bash
npm install
```

3. **تشغيل المشروع محلياً**:
```bash
npm run dev
```

4. **بناء المشروع للإنتاج**:
```bash
npm run build
```

### النشر على Cloudflare

1. **تسجيل الدخول إلى Wrangler**:
```bash
wrangler login
```

2. **تشغيل سكربت النشر**:
```bash
./deploy.sh
```

أو يدوياً:
```bash
wrangler pages deploy dist --project-name=lmm-finance-advanced-system
```

## 🛠 التخصيص

### تغيير الألوان
يمكن تخصيص الألوان من ملف `tailwind.config.js`:

```javascript
colors: {
  primary: {
    500: '#0ea5e9', // غير هذا اللون
  },
  secondary: {
    500: '#d946ef', // غير هذا اللون
  },
}
```

### إضافة مكونات جديدة
1. أنشئ ملف المكون في مجلد `components/`
2. استخدم تصميم Glass Morphism:
```jsx
<div className="glass-card">
  {/* محتوى المكون */}
</div>
```

### توسيع الوظائف
- أضف وحدات جديدة في `src/pages/`
- وسّع لوحة التحكم بمكونات جديدة
- أضف مصادر بيانات جديدة
